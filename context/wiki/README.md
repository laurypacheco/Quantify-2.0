## Antes de seguir un procedimiento

Estas guías identifican el nivel de evidencia para evitar confundir una pantalla con un flujo ya probado:

- **Pantalla documentada**: aparece en el inventario UI/UX del proyecto y/o en una captura existente.
- **Preview de diseño**: visible en el enlace de Lovable; no implica que el mismo comportamiento esté desplegado en producción.
- **Intención de prueba**: un test describe el comportamiento esperado, pero la ejecución disponible no lo confirmó.
- **Por confirmar**: las fuentes discrepan o no muestran suficiente información.

La guía general resume estas diferencias en la [matriz de capacidades](00-getting-started.md#matriz-de-capacidades) y en [información por confirmar](00-getting-started.md#informacion-por-confirmar).
